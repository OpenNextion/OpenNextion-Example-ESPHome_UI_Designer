# ONXWebStudio

ONXWebStudio 是一个纯浏览器端的 ESPHome YAML 编辑器，用来在网页里完成 OpenNextion 屏幕的可视化配置、LVGL 风格预览和最终 YAML 生成。

它适合用来：

- 在浏览器里拖拽和配置屏幕界面
- 预览接近最终 LVGL/ESPHome 的效果
- 生成可直接用于 ESPHome 的 YAML

## 支持部件

- `switch` / `multi_switch`
- `thermo_hygrometer`
- `cover`
- `light`
- `hmi_screen_brightness`
- 更多部件仍在开发中......
